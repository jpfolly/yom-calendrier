# Rappels Spirituels YOM

Calendrier d'abonnement iCalendar.

**URL d'abonnement** : https://raw.githubusercontent.com/jpfolly/yom-calendrier/main/rappels-spirituels-yom.ics

- iPhone : Réglages › Calendrier › Comptes › Ajouter un compte › Autre › Ajouter un calendrier avec abonnement.
- Google Agenda (ordinateur) : Autres agendas › + › À partir de l'URL.

Les événements sont dans `events.yaml` ; `python build.py` régénère le `.ics` ; `pytest` le valide.
